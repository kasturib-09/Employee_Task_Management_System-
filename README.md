# Employee Task Management System

A web-based **Employee Task Management System** built using Python and Django. This application helps organizations manage employees, assign tasks, track task priorities, 
and monitor task completion through a centralized dashboard.

## 📌 Project Overview

The Employee Task Management System provides a simple and organized way to manage employee responsibilities and work progress.

Admins can create and assign tasks to employees, manage employee accounts, and monitor task statuses. Employees can log in to the system and view their assigned tasks.

The system helps reduce manual work, improve task organization, and make employee task tracking easier.

## ✨ Features

- **User Authentication** – Login and logout functionality.
- **Role-Based Access** – Separate access for Admin and Employee.
- **Employee Management** – Add and manage employee accounts.
- **Task Management** – Create, view, update, and delete tasks.
- **Task Assignment** – Assign tasks to specific employees.
- **Priority Management** – Set task priorities as High, Medium, or Low.
- **Status Tracking** – Track tasks as Pending or Completed.
- **Dashboard** – View total, pending, and completed task statistics.
- **Search Functionality** – Search tasks by title.
- **Filtering** – Filter tasks by priority and status.

## 👥 User Roles

### Admin
- Login to the system.
- Add employees.
- Create and assign tasks.
- Edit task details.
- Delete tasks.
- Manage task priorities.
- Monitor task progress.

### Employee
- Login to the system.
- View assigned tasks.
- Check task descriptions.
- View task priority and status.

## 📊 Task Priorities

- 🔴 **High** – Urgent or important tasks.
- 🟡 **Medium** – Normal priority tasks.
- 🟢 **Low** – Less urgent tasks.

## 🔄 Application Workflow

1. User opens the application.
2. User logs in with valid credentials.
3. The system identifies the user's role.
4. Admin manages employees and tasks.
5. Tasks are assigned to employees with priorities.
6. Employees view their assigned tasks.
7. Dashboard statistics help monitor task progress.

## 🗄️ Database

The project uses **SQLite** and **Django ORM** for database operations.

### Main Models

- **User** – Manages authentication and user accounts.
- **Employee** – Stores employee role information linked to a user.
- **Task** – Stores task details, priority, status, assignment, and creation information.
